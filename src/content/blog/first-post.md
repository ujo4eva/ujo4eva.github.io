This is my first blog post. Written in markdown, pushed, and it just works.

## How it works

Astro content collections read markdown files from `src/content/blog/` and turn them into pages automatically.

- Drop a `.md` file in the folder
- Add frontmatter (title, date, etc.)
- Push to GitHub
- Site rebuilds
