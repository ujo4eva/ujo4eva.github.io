# ujo4eva.github.io

Personal site — Osadebamwen Uwadiae.

## Commands

| Command | Action |
|---------|--------|
| `pnpm dev` | Start dev server |
| `pnpm build` | Build to `./dist/` |
| `pnpm preview` | Preview production build |
